What this is

These pages stand in for the untrusted web content an LLM web agent reads. They are ordinary HTML served over HTTP from localhost, so the demo agent can fetch a real page and read it the way a browser agent would (visible text, DOM, hidden DOM, and the accessibility tree).

All content is fictional: *.test domains, sandbox values, simulated actions. Nothing here contacts the network, a real account, or a payment provider.

Scenarios

PageScenarioWhat it demonstrates
safe-refund-page.html Safe baseline Normal work must not be disrupted
visible-injection.html Direct injection Override wording in plain sight
aria-injection.html Hidden ARIA injection Payload in an accessible name, invisible on screen
injecagent-indirect-hijack.html Indirect web hijack Benchmark-style tool hijack across three views
task-deviation-settings.html Task deviation Directive with no override wording — the action gate decides
benign-aria-negative.html Hard negative Imperative accessible name that must not be blocked

Run the agent against these pages

npm run agent:demo -- --all

The agent fetches each page over HTTP, the protection layer scans it, and the run is printed in the terminal and written to apps/demo-web/public/agent-runs/latest.json for the dashboard's Agent Console panel.

Note for reviewers: these pages declare their episode metadata in ctxvigil:* meta tags (task, proposed action, asserted verdict). The agent runner reads those tags so the demo is reproducible and self-checking; a page whose engine verdict stops matching its declared verdict fails loudly instead of quietly.
